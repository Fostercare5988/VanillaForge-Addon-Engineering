# Archive

Earlier VanillaForge material, kept for history. It is not part of the working
contract; [VANILLAFORGE.md](../VANILLAFORGE.md) replaced it on 21 October 2026.

| Folder or file | What it was |
| --- | --- |
| `VANILLAFORGE_SYSTEM_PROMPT.md`, `CORE.md` | The previous contracts (framework 3.2) |
| `docs/` | Workflows, release procedure, decision log, target environment, ClassicAPI release audits 1.15.12 to 1.16.0 |
| `agent/` | Task, review, retrospective and upstream audit templates |
| `audit/` | Dated OctoWoW client and portfolio audits with their evidence |
| `TARGET_ENVIRONMENT.json` | Machine-readable OctoWoW target, now in [servers/octowow.md](../servers/octowow.md) |
| `tools/`, `tests/` | Checkers for the old document structure and the client manifest tool. They no longer run. |

The ClassicAPI release audits are still linked from the ClassicAPI reference as
the evidence behind some of its entries.
