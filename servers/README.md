# Server profiles

VanillaForge targets the WoW 1.12.1 client and its extension DLLs, which are the
same on every server. Game data is not: each server decides its own spells,
items, numbers and rules. A profile records, for one server, where that data
may come from and what is known about it.

| Profile | Server |
| --- | --- |
| [octowow.md](octowow.md) | OctoWoW |

The workspace `CLAUDE.md` names the active profile. For a new server, copy
[TEMPLATE.md](TEMPLATE.md).
